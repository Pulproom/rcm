# Risu Cognitive Memory 설치 안내

이 설치 파일은 **Windows 10/11 x64**용입니다. Node.js와 SQLite 실행 환경이 포함되어 있으므로 별도 설치나 관리자 권한이 필요하지 않습니다.

## 설치 및 시작

1. ZIP 파일 전체를 원하는 폴더에 압축 해제해 주세요.
2. `Start.cmd`를 실행해 주세요.
3. `Connection.cmd`를 열어 서버 주소와 토큰을 확인해 주세요.
4. RisuAI 또는 PocketRisu에서 `risu-cognitive-memory.js`를 플러그인으로 설치해 주세요. 목록에는 `Risu Cognitive Memory 1.0.0`으로 표시됩니다.
5. 플러그인 연결 설정에 주소와 토큰을 입력해 주세요.
6. 프롬프트에서 기억을 넣을 위치에 `[[RCM]]`을 한 번 배치해 주세요.
7. RCM 대시보드에서 Voyage API와 보조 모델을 설정해 주세요.

기본 주소는 `http://127.0.0.1:7331`입니다. 같은 포트를 다른 프로그램이 사용하고 있다면 서버를 종료하거나, 첫 실행 전에 `RCM_PORT` 환경 변수로 다른 포트를 지정해 주세요. 시작 오류는 사용자 데이터 폴더의 `server-error.log`에서 확인할 수 있습니다.

서버를 종료하려면 `Stop.cmd`를 실행해 주세요. 서버는 백그라운드에서 실행되므로 시작 창을 닫아도 계속 동작합니다.

## 업데이트

대시보드와 플로팅 UI에서 새 버전을 자동으로 확인합니다. 대시보드에서 **서버 업데이트 설치**를 누르면 새 서버 파일의 크기와 SHA-256 체크섬을 확인하고 서버를 다시 시작한 뒤 적용 결과까지 확인합니다. 새 서버가 시작되지 않으면 런처가 이전 서버 파일을 자동으로 복원합니다.

예전 버전에서 자동 업데이트 기능이 들어간 버전으로 처음 넘어갈 때에는 화면의 안내에 따라 `Stop.cmd`, `Start.cmd` 순서로 서버를 한 번 다시 시작해 주세요. 그다음 업데이트부터는 대시보드 버튼으로 진행할 수 있습니다.

서버 업데이트가 끝난 뒤 Risu의 플러그인 `+` 메뉴에서 플러그인 업데이트를 진행해 주세요. 플러그인과 서버의 API 계약이 맞지 않으면 RCM은 메인 모델 호출 전에 요청을 중단하고 필요한 업데이트를 안내합니다.

설정·토큰·기억 DB는 설치 폴더 옆의 `RCM-user-data`에 저장되며 서버 실행 파일과 분리되어 있습니다. 업데이트 전에 대시보드에서 전체 백업을 만들어 두시기를 권장합니다. 전체 백업을 다른 설치에 복원해도 복원 대상의 서버 주소와 토큰은 유지됩니다. 수동으로 ZIP을 교체할 때에도 `RCM-user-data`는 삭제하거나 덮어쓰지 마세요.

## 데이터와 지원 범위

`RCM_DATA_DIR` 환경 변수로 사용자 데이터 위치를 바꿀 수 있습니다. `connection.json`과 사용자 데이터 폴더에는 비밀키와 대화가 있으므로 공유하지 마세요.
